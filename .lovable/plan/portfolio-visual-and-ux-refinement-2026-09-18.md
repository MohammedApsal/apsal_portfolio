# Portfolio visual and UX refinement

## Goal
Polish the existing portfolio without changing its dark AI-growth identity, content, portrait, or working contact experience. Bring business problems, practical solutions, workflows, and project proof forward.

## Changes

1. **Refine the page flow**
   - Reorder the existing homepage to: Hero → Problems → Services → Lead-to-Customer workflow → Case Studies → Business Outcomes / Why Work With Me → Process → About → compact Technology / Expertise → Contact.
   - Preserve all existing sections and anchor navigation.

2. **Polish the hero**
   - Slightly reduce headline scale and create more breathing room around the copy.
   - Replace the portrait’s flat light treatment with a deeper transparent blue/violet integration, subtle glow, and restrained floating labels.
   - Keep the portrait, copy, status, and calls to action unchanged.

3. **Make case studies the visual centerpiece**
   - Add six custom, responsive product-interface mockups built from lightweight UI elements:
     - Meta Ads → lead capture → automation → CRM
     - Business website on laptop and phone
     - AI lead-scoring dashboard with HOT / WARM / COLD
     - Email intelligence inbox with priority and summary
     - Customer support chat with knowledge and escalation
     - RAG document pipeline plus document chat
   - Keep every existing Problem → Solution → Workflow → Tech Stack → Project Type → Outcome field.
   - Improve card hierarchy, visual scale, border/glow hover, and subtle visual zoom without adding fake links.

4. **Upgrade business-focused sections**
   - Turn “From Lead to Customer” into a clearer automation architecture with connected nodes, qualification states, tools, and animated paths.
   - Refine problem cards with stronger icon hierarchy and restrained interaction.
   - Lead service cards with the requested business-result statements while preserving tags and impact boxes.
   - Add the personal statement to “Practical AI. Real Business Problems.”
   - Present the six delivery stages as a connected professional process.

5. **Reduce technology emphasis and improve consistency**
   - Keep expertise and technology categories, but present them as compact supporting groups after About.
   - Tighten spacing, card consistency, section rhythm, and final contact emphasis using the existing colors, typography, glass effects, and animation language.

6. **Validate the finished site**
   - Check desktop, tablet, and mobile for horizontal overflow, readable diagrams, portrait positioning, one-column case studies, touch-friendly controls, working navigation/contact links, loaded images, and runtime errors.
